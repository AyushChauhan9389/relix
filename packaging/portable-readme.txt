Relix (portable)
================

Run relix-app.exe. Nothing is installed: your addons, My List, progress and
account sign-in are kept in the "data" folder next to it, so you can carry this
folder anywhere (USB stick, another PC).

Delete the file named "portable" to make this copy use your Windows profile
(%APPDATA%\relix) instead.

Files
  relix-app.exe     the app
  libmpv-2.dll      the video player engine (mpv, LGPL; with FFmpeg)
  relix-server.exe  optional: your own sync server (see README on GitHub)
  portable          marker that keeps data next to the app

Source and docs: https://github.com/AyushChauhan9389/relix
